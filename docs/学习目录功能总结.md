# 学习目录功能总结

## 1. 功能概述

学习目录（LearningPath）是《数据结构》智慧学习平台的核心导航模块，以**左侧树形目录 + 右侧详情内容**的左右分栏布局，为学习者提供清晰的知识结构浏览与精准跳转能力。

## 5. 路由结构

```
/knowledge                         ← LearningPath/index.vue（布局容器）
  /welcome                         ← KnowledgeDetail（默认占位）
  /:module                         ← KnowledgeDetail（按模块浏览）
  /:module/:id                     ← KnowledgeDetail（按知识点ID浏览）
```

点击左侧树节点后，路由跳转 `{ name: 'KnowledgeDetail', params: { module, id } }`，右侧 `<router-view>` 渲染 KnowledgeDetail 页面。

## 6. 数据流

```
┌─────────────┐      ┌──────────────────┐      ┌───────────────┐
│  MySQL       │      │  Backend API     │      │  Frontend     │
│              │      │                  │      │               │
│ knowledge    │─────▶│ KnowledgePoint   │─────▶│ el-tree       │
│ _point       │ tree │ Service 构建树    │ tree │ 组件渲染目录   │
│              │      │                  │ Data │               │
│ learning     │─────▶│ GET /learning/   │─────▶│ 状态圆点       │
│ _progress    │ map  │ progress         │      │               │
│              │      │ （待实现）         │      │               │
└─────────────┘      └────────┬─────────┘      └───────┬───────┘
                              │                          │ 用户 hover
┌─────────────┐      ┌───────▼─────────┐      ┌───────▼───────┐
│  Neo4j       │      │  Backend Service│      │  Frontend     │
│              │      │                  │      │               │
│ RELATED_TO  │─────▶│ loadPrerequisites│─────▶│ tooltip 提示   │
│ (关系)       │Cypher│ FromNeo4j()      │嵌入树 │ 推荐学习顺序   │
│              │      │                  │节点   │               │
└─────────────┘      └──────────────────┘      └───────────────┘
```

前置依赖数据在 `KnowledgePointService.buildKnowledgeTree()` 中通过 Neo4j Cypher 查询 `MATCH (n)-[:RELATED_TO]->(prereq)` 获取，并嵌入到 `/api/knowledge/tree` 响应的每个节点的 `prerequisites` 字段中（`List<String>` 类型，值为前置知识点的 neo4j_id）。前端通过 `neo4jIdIndex` 将 neo4j_id 映射为知识点中文名后展示。

## 7. 技术要点

- **树组件**：Element Plus `el-tree`，`node-key="id"`，`accordion` 手风琴模式
- **搜索过滤**：`filter-node-method` 按 name（中文）和 code（英文）双重匹配
- **状态渲染**：自定义 `#default` 插槽，左侧圆点 + 右侧难度标签 + 前置依赖图标
- **路径引导**：`el-tooltip` hover 显示前置依赖知识点名列表
- **分栏布局**：flex 左右分栏，左侧 320px 固定，右侧 flex:1 自适应
- **全屏适配**：`height: calc(100vh - 56px)` 确保白色背景始终触底

## 12. 编码问题注意事项

学习目录模块依赖 MySQL 和 Neo4j 双数据库，开发调试时需特别注意字符集一致性：

- **MySQL Docker**：`docker-compose.yml` 必须包含 `--character-set-client-handshake=FALSE`，确保初始化 SQL 脚本以 `utf8mb4` 正确写入
- **JDBC 连接串**：`application.yml` 中需配置 `characterEncoding=UTF-8` 和 `connectionCollation=utf8mb4_unicode_ci`
- **Neo4j entrypoint.sh**：顶部需声明 `export LANG=C.UTF-8` 和 `export LC_ALL=C.UTF-8`
- **SQL / Cypher 文件**：保存时确保使用 UTF-8 编码（无 BOM）
